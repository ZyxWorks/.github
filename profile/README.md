## Zyx

**Ask your company. On your own server.**

Zyx knows your company's mail, files and apps. It answers questions and names the source of every answer, and it asks you before every risky action. It runs on your company's own server. Zyx is in a private beta, set up at your office by an engineer from Zyx, and it is not open source. **[zyx.works](https://zyx.works/en/)**

These are the tools we built for our own work and gave away. Both run on your own machine, both are MIT, and neither one sends telemetry.

| | |
|---|---|
| **[MurmurFlow](https://github.com/ZyxWorks/murmurflow)** | Dictation that runs on your own machine. Tap a key, talk, and the words land at your cursor in any app. macOS and Windows. [Product page](https://zyxworks.github.io/murmurflow/) |
| **[Agent Office](https://github.com/ZyxWorks/agent-office)** | The whole setup for running several coding agents side by side, each in its own git worktree. You see which one needs you. macOS and Linux. [Product page](https://zyxworks.github.io/agent-office/) |
