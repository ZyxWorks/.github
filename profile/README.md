## ZyxWorks

A product studio and forward deployed engineering practice — **[zyxworks.com](https://zyxworks.com)**.

These are the tools we built for our own work and gave away. Both run on your own machine,
both are MIT, and neither one sends telemetry.

| | |
|---|---|
| **[MurmurFlow](https://github.com/ZyxWorks/murmurflow)** | Dictation that runs on your own machine. Tap a key twice, speak, tap again, and the words land at your cursor in any app. macOS and Windows. [Product page](https://zyxworks.github.io/murmurflow/) |
| **[Agent Office](https://github.com/ZyxWorks/agent-office)** | A workspace for your coding agents, each in its own git worktree. You see which one waits for you. [Product page](https://zyxworks.github.io/agent-office/) |

Both came out of **[Zyx](https://zyxworks.com/en/)**, the runtime the studio runs on: one AI you
message like an employee and approve like the boss. Zyx is not open source, and putting it into a
company's own tools is **[what we sell](https://zyxworks.com/en/#pricing)** — five phases, each with a
date, finished inside 120 days.
